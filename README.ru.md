# password-generation

Enterprise-grade кроссплатформенное десктопное приложение на Python для **автоматической генерации криптостойких паролей** по заданным критериям безопасности с привязкой к списку сотрудников (ФИО).

Проект спроектирован по канонам **Чистой Архитектуры (Clean Architecture)** с полным разделением бизнес-логики (`core.py`) и графического интерфейса (`view.py`).

## ✨ Ключевые особенности

*   **Архитектурный паттерн:** Изолированное ядро (Engine), готовое к масштабированию и переносу на Web/Telegram-ботов.
*   **Реактивный UI на CustomTkinter:** Современный адаптивный интерфейс с поддержкой вкладок, динамическим пересчётом параметров и изменением темы оформления.
*   **Многопоточность (Threading):** Тяжёлые операции файлового ввода-вывода вынесены в отдельный поток, что исключает «зависание» интерфейса.
*   **Security-First подход:** Генерация паролей через изменяемый пул байт (`bytearray`) с последующим принудительным занулением памяти для защиты от атак через дампы RAM.
*   **Защита окружения (Path Traversal Protection):** Изоляция файловых операций внутри корневой директории приложения, блокировка доступа к системным и скрытым каталогам (`.venv`, `__pycache__`).

## 📁 Структура проекта

*   `main.py` — Главная точка входа, инициализирующая жизненный цикл приложения.
*   `view.py` — Графическая оболочка приложения (GUI), содержащая логику вкладок, радиокнопок и мультиязычность.
*   `core.py` — Изолированная бизнес-логика, отвечающая за криптогенерацию, конфигурацию пулов и безопасность памяти.
*   `requirements.txt` — Файл фиксации внешних зависимостей проекта для быстрой репликации окружения.
*   `ROADMAP.ru.md` — Технический план развития утилиты до уровня Enterprise с фиксацией выполненных этапов.
*   `FioLatinica.txt` — Входной файл со списком ФИО сотрудников (генерируется автоматически при отсутствии).
*   `PasswdFile.txt` — Выходной файл отчета с готовыми парами ФИО-Пароль (создается автоматически).

## 🚀 Быстрый старт (Развёртывание)

Программа автоматически инициализирует окружение. При первом старте она самостоятельно создаст демонстрационный файл `FioLatinica.txt` в своей директории.

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.12+. Склонируйте репозиторий и перейдите в папку проекта:

```bash
git clone https://github.com/viktor-babeev/password-generation.git
cd ./password-generation
```

### 2. Создание и активация виртуального окружения
*   **Windows (cmd):**
    ```cmd
    python -m venv .venv
    .venv\Scripts\activate.bat
    ```
*   **Linux / macOS:**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

### 3. Установка зависимостей и запуск
```bash
pip install -r requirements.txt
python main.py
```

## 🛠️ Технологии

*   **Language:** Python 3.12+
*   **GUI Framework:** CustomTkinter (Tkinter wrapper)
*   **Core Modules:** `secrets` (Cryptographically secure pseudo-random number generator), `threading`, `os`, `sys`, `ctypes`
